# 九图 A+ 制作简报模板

与 [九图规范](../references/nine-image-business-pc.md)、[提示词模板](nine-image-prompts.md) 一起使用。复制到准确产品目录，例如 `products/<Virtual-ID>/<marketplace>/nine-image-brief.md`，再将本模板的链接改为新位置的正确相对路径。这里的待填写项只用于简报；生成前必须替换或明确省略，不让占位符进入图片。

## 产品与适用范围

- Virtual ID／SKU／ASIN／站点／目标配置：待填写
- 制作日期／事实版本／上游仓库与 commit：待填写
- 产品类型／受众／判断依据：待填写
- OEM／销售定制身份／Logo 来源与授权：待填写
- 外观依据：准确产品正面／角度／背面路径及 SHA-256；未覆盖角度：待填写
- 资料证据入口：事实表／research ledger／现有 Research Review／Listing Draft（存在时关联，不无故重做）：待填写
- 当前 ERP／制造商／Amazon 访问结果与限制：待填写
- 新产品风格预览路径／用户选择原文／日期：待填写，未批准前不得标 USER_APPROVED
- 本次 GitHub 交付范围／其他目的地授权：待填写；不预设 Seller Central 发布

## 风格锁定

- 风格参考：VD-744 九图基线 `84bb002e4f1d8c064bba3df694aa920cca43c280`；只借用风格，参数另核实
- 本产品已有 Listing 风格／用户覆盖选择：待填写
- 色板：主标题／强调／底色／卡片／分隔线：待填写
- 字体：标题／正文／数字／可用替代字体；字号与行高：待填写
- 母版目标尺寸／真实导出尺寸：待填写；约 3:1 是创意母版，后台规格另查
- 留白／Logo 位置／产品占比／卡片圆角／图标笔画：待填写
- 摄影：桌面、窗光方向、机位、产品角度、接触阴影：待填写
- 场景设备：同品牌代表性显示器／键盘／鼠标外观及参考来源；不借此确认随附型号或连接方式
- 禁用：无证据参数、价格／加价、虚构性能、科幻灯效、重复口号；本次新增禁用项：待填写

## 逐图检查与批准

- [ ] 九个文件各自回答一个问题；重叠有明确的速览／深入分工
- [ ] 所有硬件参数、型号后缀、单位、选项口径和限定文案核对
- [ ] 真实外观、端口、Logo、机身小字、手指与接触阴影逐张看过
- [ ] 场景外设大小自然，道具与实际随附内容分开说明
- [ ] 375／390 px 缩略检查只记录实际结果；未适配移动端的限制显式保留
- [ ] 用户看到具体预览并批准本次风格；批准图哈希／原文／日期已记录
- [ ] Basic／Premium copy、alt、delivery gallery 与九图主题一致
- [ ] manifest 记录真实宽高／字节／SHA-256；参考与提示词路径有效、正文完整
- [ ] 敏感资料及签名链接筛查；授权／视觉／结构／后台状态分开记录
- [ ] GitHub 上传授权、旧版本保留、远端字节核对和缓存清理分别记录
