# 从已有 Listing 复用资料与自动判断内容方向

2026-10-27 当前补充：[九图商务 PC 规范](nine-image-business-pc.md) 记录 VD-744 批准后的九图分工与详细设计格式。相似产品从该规范与九图简报开始；下文旧 Listing 源仓库 commit 是历史映射，不作当前远端版本依据。新印到图上的技术参数遵循当前 [WORKFLOW](../WORKFLOW.md) 官方资料优先链；现有资料只在身份、日期、范围和证据仍适用时复用。

2026-10-15 用户确认：通常沿用已有 Listing 的图片与风格，以增强购买意愿为目标；主动判断产品类型与受众，不把“属于什么风格”作为每次必须回答的问题。制作先完成设计方案，后台模块适配可以后做。

这是一份方法映射，不是把整个 Listing 生成流程复制过来。本次不要求重做 Excel、MAIN/PT 槽位或无关合规字段；A+ 自己的内容结构、尺寸与后台适配单独处理。Listing 工作簿的固定保修段落、基础配置规则不自动成为 A+ 模块规则；遵循用户本次内容范围及可证实事实。

## 每次接到产品的自动处理顺序

1. 读取指定 Listing / ERP，确认 Virtual ID，定位上述精确产品目录。先看当前 facts、delivery-status、style-lock，再看图像成品。
2. 对比 CPU/GPU、内存/SSD、形态、显示屏、颜色、系统、接口和随附内容。旧文件与当前输入不一致时保留差异；按匹配官方资料 > ERP > 准确 Amazon 变体补查与解决，区分出厂／实机／家族／销售选项，未验证卖点暂不定稿，不先把冲突全部转问用户。
3. 识别硬件类别：笔记本 / Micro 或 Mini / SFF / Tower / AIO / 工作站 / 其他；没有显示屏的主机不套笔记本 LCD 设计。
4. 根据 Listing 定位、实际硬件和使用任务判断受众，并记录依据及信心：明确 / 可合理推断 / 不确定。只有类别或用途会显著改变内容且证据不足时才问用户。
5. 检查现有 Listing 的产品角度、Logo、色板、字体层级、背景、卡片形状、图标、留白和语气。默认沿用能识别为同一产品的视觉语言，重新组织信息而非逐图复制。
6. 在 PCOnline、IST 店内先找同机型，其次同形态与同用途商品。读取实际 A+ 区域和轮播，不用店铺首页或 MAIN 图片代替 A+ 分析。每家默认 1 个代表商品；必要时补 1 个。
7. 输出“事实 → 买家问题 → 购买理由 → 证据画面 → 模块位置”，优先解决影响选择的疑虑。
8. 生成 Basic / Premium 两套设计方案及视频脚本。记录本次用户选择、推断项、暂缓项和来源。

9. 要求类似 VD-744 九图时采用九图分工、逐张提示词和真实图文规格，不沿用旧六图的重复企业／居家摆拍；新产品／重大风格变化的具体预览仍由用户批准。

## 产品定位与风格路由

| 判断依据 | 默认内容方向 | 需要突出 | 不可仅凭该依据推断 |
|---|---|---|---|
| 商务 Listing + 办公型号 + Micro/SFF | 企业 / 居家办公 | 空间、处理器、连接、配置与系统 | 企业级部署能力、静音、特定多屏数量 |
| 游戏 Listing + 相应 GPU / 产品定位 | 游戏 | 实际 GPU、体验任务、散热结构与扩展 | FPS、性能提升百分比、某游戏设置表现 |
| 便携、学习或家庭定位 | 学习 / 日常 / 通用 | 便携、屏幕、输入、学习任务 | 续航时长、抗摔或儿童专用资格 |
| 明确工作站定位及相应硬件 | 专业工作站 | 对应工作任务、硬件与连接证据 | 软件认证、渲染耗时、工程项目规模 |
| 证据不足或定位混合 | 延续现有 Listing 的中性方向 | 已确认的产品价值 | 自动归类为电竞、AI 专用或专业工作站 |

该表是设计判断方法，不是性能认证。未来 Dell、HP、Lenovo 等产品使用各自真实 OEM 标识与 Listing 风格，不把本次 Dell 选择套给整个目录。

## 增强购买意愿的具体做法

- 开头让买家在几秒内知道“是什么、适合谁、为什么考虑”。
- 把参数翻译成具体任务价值，再展示相应证据，避免空泛口号。
- 优先回答：是否适合我的工作、占多大空间、怎么连接、配置如何选择、包含什么。
- 每个模块一个主要购买理由；同一个规格不在多屏重复堆砌。
- 结尾帮助正确选择配置，不虚构稀缺性、优惠、竞品劣势或评价。
- 记录本次优化假设，例如“减少容量误解”；上线后如有合法可用数据，再评估转化表现。设计方案不宣称必然提升销量。

## 每个项目必须记录

`产品分类 / 受众判断与依据 / 现有 Listing 风格 / OEM Logo 来源 / 精确产品图来源 / 两家参考 ASIN / 模块观察与采用方式 / 配置适用范围 / 待核实事实 / 方案状态 / 后台适配状态`。
